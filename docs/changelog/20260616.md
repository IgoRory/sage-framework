# Changelog - 2026-06-16

## Add PROF-512 Hook Contract Test Foundation

### Rationale

The hook migration needs a local contract check and a shared tool registry so Cursor tool-name changes do not silently bypass SAGE gates during plugin rollout.

### Changes

- Added plugin hook path verification and referenced hook script compile/import checks.
- Centralized supported Cursor read, write, shell, and read-only tool names in `hooks_utils.py`.
- Updated required-reference and drift checks to use the shared registry and current/legacy telemetry shapes.
- Added focused hook tests and local E2E result notes for the contract foundation.

### Regression Avoidance

- Kept live Cursor exit-code blocking as a documented TODO rather than treating local contract checks as full plugin cutover proof.
- Limited scope to the PROF-512 hook contract and registry foundation; no fail-open wrapper, metadata migration, Profitability de-vendor, or hooks-spec modernization was added.

## Add PROF-512 Fail-Open Hook Gate Wrapper

### Rationale

Blocking SAGE hook gates should not strand Cursor tool execution when a gate crashes unexpectedly during plugin migration; unexpected failures need a visible debug trail while preserving deliberate block and permit outcomes.

### Changes

- Added a shared `run_gate` wrapper that lets intentional `SystemExit` gate outcomes pass through unchanged.
- Logged unexpected hook crashes to `.sage/.hook-debug.log` with script name, exception details, and a captured stdin payload head.
- Wrapped blocking gate entrypoints and `plan_mode_enforcer.py` / `test_write_guard.py` with the shared fail-open runner.
- Added focused coverage for unexpected gate crash permit behavior and structured debug logging.

### Regression Avoidance

- Preserved explicit gate block behavior by only failing open on unexpected exceptions.
- Limited scope to runtime gate resiliency; no step 5 cutover, metadata migration, Profitability de-vendor, hooks mode safe-mode, or hooks-spec modernization was added.

# Changelog - 2026-06-16

## Add PROF-512 Hook Contract Test Foundation

### Rationale

The hook migration needs a local contract check and a shared tool registry so Cursor tool-name changes do not silently bypass SAGE gates during plugin rollout.

### Changes

- Added plugin hook path verification and referenced hook script compile/import checks.
- Centralized supported Cursor read, write, shell, and read-only tool names in `hooks_utils.py`.
- Updated required-reference and drift checks to use the shared registry and current/legacy telemetry shapes.
- Added focused hook tests and local E2E result notes for the contract foundation.

### Regression Avoidance

- Kept live Cursor exit-code blocking as a documented TODO rather than treating local contract checks as full plugin cutover proof.
- Limited scope to the PROF-512 hook contract and registry foundation; no fail-open wrapper, metadata migration, Profitability de-vendor, or hooks-spec modernization was added.

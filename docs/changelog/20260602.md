# Changelog - 2026-06-02

## Sync PROF-414 PRD Process Robustness

### Rationale

The Profitability PRD interview flow was upgraded into an L1-L12 pipeline with
stronger preflight checks, phase-specific interview conduct, split question
sets, downstream artifact contracts, manual handoff briefs, and PRD robustness
evaluation signals.

SAGE Framework needs the same framework-level guidance so new repositories can
start from the improved PRD process rather than relying on the older monolithic
interviewer and question-set files.

### Changes

- Reworked `prd-interviewer` into a thin L1-L12 coordinator backed by
  phase-specific interview conduct references.
- Split the legacy `question-sets.md` reference into per-section question-set
  files with shared usage and challenger-probe guidance.
- Added PRD bundle contract references for section schema, acceptance criteria,
  traceability, component specifications, handoff prompts, telemetry, and
  production quality expectations.
- Added PRD lifecycle skills for amend, orchestration, stale-check, and
  walkthrough flows.
- Updated downstream consumers including `phase-splitter`,
  `prd-completeness-check`, `prd-demo-generator`, kickoff review, and the PRD
  interviewer effectiveness evaluator to consume the new bundle contract and
  telemetry signals.
- Updated the agent catalogue so the new PRD lifecycle skills are discoverable.

### Regression Avoidance

- Preserved SAGE artifact boundaries by keeping the PRD interviewer as a
  coordinator and moving detailed behaviour into reference modules.
- Removed the superseded monolithic question-set file after adding the split
  question-set directory to avoid competing sources of truth.
- Did not import Profitability runtime telemetry data; the framework keeps only
  the telemetry schema and path references needed by downstream repositories.
- Kept changelog scope to framework guidance and skill/catalog updates, with no
  product source or runtime configuration changes.
